# OpenScore/Lieder enrichment snapshot

`lieder_enrichment.tsv` подготовлен для 1356 строк `data/scores.tsv` из
[OpenScore/Lieder commit `6b2dc54`](https://github.com/OpenScore/Lieder/commit/6b2dc542ce2e8aa4b78c8ee62103b210efc07015).

Колонки:

- `score_id` — `scores.tsv.id`, который текущий `import_lieder.py` сохраняет в
  `Score.source_id`;
- `set_id` — цикл/набор из `scores.tsv`;
- `difficulty` — `1` (easy), `2` (intermediate), `3` (hard);
- `tags` — отсортированные slug тегов через запятую.

## Как собраны теги

Общие теги описывают корпус (`classical`, `art-song`, `piano`).
Остальные получены из проверенных метаданных `composers.tsv`, `sets.tsv` и
`scores.tsv`: эпоха и страна композитора, пол автора, настоящий песенный цикл,
известные направления отдельных композиторов, а также тематика названия
произведения/цикла (любовь, природа, ночь, времена года, духовная музыка,
колыбельные, танцы и т. п.).

Теги добавляются к существующим и не удаляют ручную разметку.

## Как оценена сложность

Это приблизительная исполнительская сложность, рассчитанная по каждому
официальному MusicXML корпуса. Учитывались:

- плотность нот относительно числа тактов;
- доля быстрых длительностей;
- аккордовая и полифоническая фактура;
- tuplets, grace notes и ритмическое разнообразие;
- хроматика, число голосов и протяжённость произведения.

Пороговые значения откалиброваны относительно всего корпуса. Распределение:

- easy (`1`) — 417 произведений;
- intermediate (`2`) — 696 произведений;
- hard (`3`) — 243 произведения.

Это практическая трёхуровневая оценка для фильтра каталога, а не официальная
экзаменационная градация.
